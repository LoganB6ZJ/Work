## Stack and design choices

- Python, SQLite, pandas, openpyxl, Flask (Flask chosen as the default; no other web framework was requested).
- Scripts print counts and center IDs only. `import_log` stores counts only.
- Importers are command-line scripts. A snapshot is identified by file hash plus snapshot date. Re-running a file changes nothing. A second, different file for a date already loaded is refused.
- The painter importer refuses to run until `ALLOWLIST_CONFIRMED = True` in `config.py`.
- Header drift: any painter file whose headers differ from the expected set is reported and not loaded.
- `--org-sheet` was added to `import_centers.py` because the org chart is a tab inside the Selection Tool workbook.
- A center that is in the Selection Tool but not the org chart (usually closed) is kept as a stub row so history is not lost. The org chart fills it in if it appears later.
- Position Start Date is shown as a corroborating signal only.
- Region benchmarks are not loaded (`BENCHMARK_REGION_SOURCE = None`) because the painter file has no region column.
